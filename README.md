# 保養所プライスボード (hoyoujo)

ITS健保等の保養所および提携ホテルの料金（1泊2食付）を、指定した日付・人数で横並びに比較・空室確認ができる単一ページWebアプリケーションです。  
楽天トラベルAPI（新API: `openapi.rakuten.co.jp`）をブラウザから直接呼び出し、最新の最安プラン料金・空室状況を取得します。

デプロイ先: [https://nandkou.github.io/hoyoujo/](https://nandkou.github.io/hoyoujo/)

---

## 主な機能

* **1泊2食付の最安プラン検索**:
  * 空室検索時に「朝食あり・夕食あり」の絞り込み条件（`squeezeCondition=breakfast,dinner`）を自動適用し、1泊2食付の最安プラン料金および直接の予約URL・プラン名を取得します。
* **スマートな日付連動（泊数固定）**:
  * チェックイン日を変更した際、選択されている泊数（デフォルト1泊）を維持したままチェックアウト日が同日数分自動でシフトします。
  * チェックアウト日を変更するとその泊数が記憶され、以降のチェックイン変更時もその泊数が維持されます。
* **APIキーのローカルストレージ保存**:
  * 入力した楽天ウェブサービスの「アプリID」と「アクセスキー」は、ブラウザの LocalStorage に自動保存されます。
  * 次回アクセス時も自動入力されるため、毎回の再入力が不要です（有効期限なし・必要に応じてワンクリックで削除可能）。
* **料金結果のキャッシュ機能**:
  * 同一検索条件（日程・人数・食事条件）の検索結果を LocalStorage にキャッシュし、無駄なAPI呼び出しを削減して高速に表示します。
* **絞り込み・ソート機能**:
  * 都道府県、エリア、施設名キーワードによるリアルタイム絞り込み。
  * 料金順（最安値昇順・降順）、空室状況順、施設名順でのソート。
* **施設番号（hotelNo）の手動指定**:
  * 施設名での自動照合が難しい場合や取扱外の場合、楽天トラベルの施設番号（hotelNo）を入力して1件ずつ個別再取得が可能です。
* **レスポンシブ対応**:
  * PCおよびスマートフォン（640pxブレークポイント）に最適化された見やすい和風モダンUI。

## 使い方

1. **楽天ウェブサービスでAPIキーを取得**
   * [楽天ウェブサービス](https://webservice.rakuten.co.jp/) に無料登録し、アプリを作成します。
   * 発行された **「アプリID」** と **「アクセスキー」** をコピーします。
   * ※ 楽天新APIの仕様上、アプリ作成時の「アプリURL」にはデプロイ先URL（例: `https://nandkou.github.io/hoyoujo/`）を登録してください。
2. **プライスボード画面でAPIキーを設定**
   * 画面上部の「楽天トラベルAPI設定」欄にアプリIDとアクセスキーを入力し、「保存」をクリックします。
   * 「APIキーをテスト」ボタンを押して疎通が成功することを確認します。
3. **条件を指定して検索**
   * チェックイン日・大人人数を指定し、「この条件で料金を検索」ボタンを押します。
   * 一覧に各施設の最安料金（1室税込総額）と空室状況が表示され、「プランを見る」から楽天トラベルの予約画面へ直接遷移できます。

## 開発・ローカル実行

本プロジェクトは外部ライブラリやビルドツールの依存関係がない、単一HTMLファイル（`index.html`）構成です。

### ローカルサーバーの起動

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開きます。

> **注意（楽天APIのOrigin検証について）**:  
> 楽天新API（`openapi.rakuten.co.jp`）は、登録されたアプリURLのOrigin（例: `https://nandkou.github.io`）と異なる環境（`localhost` や `file://`）からのリクエストに対して認証エラーを返します。ローカルで動作確認する場合は、楽天Developers管理画面でローカル用URLを登録した別アプリを作成するか、GitHub Pages上でお試しください。

### ローカル用APIキー設定（任意）

ローカル環境での開発用に、Git管理外の `env.js` または `.env` からAPIキーを自動読み込みできます（どちらも `.gitignore` 済みです）。

**`env.js` の例:**
```javascript
window.__ENV__ = {
    APPLICATION_ID: "あなたのアプリID",
    ACCESS_KEY: "あなたのアクセスキー"
};
```
